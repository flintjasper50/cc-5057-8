How to start the workbench

The spawn design is a graphical workbench. Run npm install then npm run dev and open the printed URL (default http://localhost:5173). Everything below is done in that window.

The screen

  • Left rail — scene picker, mode, spawn conditions, editable spawn zones, and door flips.
  • Centre stage — the 3D level with spawn zones, candidate region, rejected markers, routes, sightlines, and the live replay.
  • Right rail — the outcome, accepted pairs, the selected pair's scores and per-record evidence, the actual encounter, rejections, flip counterfactual, and the scene log.

What the window does

  1. Pick a scene (symmetric, one-way gate, elevation split).
  2. Choose Fair opening or Asymmetric chase.
  3. Adjust spawn conditions. Hard limits that accept or reject are labelled separately from soft weights, which only rank.
  4. Click Run design. Candidates appear in the level; the result rail lists pairs, scores, rejections and the raw geometry/nav queries behind each score.
  5. Drag a spawn-zone edge under Spawn zones to adjust the actual spawn conditions, then re-run. The revision bumps and stale results are revoked.
  6. Select a pair, then Play to dispatch both characters along their real routes. The Actual encounter panel compares the candidate region with where the two characters really meet.
  7. Flip a one-way door and re-run to watch the advantage change sides.

Command line (auxiliary only)

The graphical workbench is the primary entry. npm test, npm run check and npm run verify are maintenance/verification helpers; they do not replace the window.
